# 🚀 Dapoy Bluestack Tweaker

**Dapoy Tweak Emulator** adalah aplikasi All-in-One Tweaker super lengkap yang dirancang khusus untuk mengelola, mengatur, dan memberikan akses kontrol penuh ke emulator Android kesayangan Anda (BlueStacks 5 dan MSI App Player). 

Dibangun dengan antarmuka yang bersih, simpel, dan elegan, aplikasi ini memastikan pengalaman _tweaking_ emulator Anda menjadi jauh lebih cepat, aman, dan tanpa hambatan.

---

## ✨ Fitur Unggulan

- 🔧 **Manajemen Emulator Lengkap:** Bypass root, ganti resolusi, ubah RAM & CPU core dengan sekali klik.
- ⚡ **Auto-Installer:** Instal APK langsung ke dalam emulator tanpa repot tarik-geser.
- 📦 **Magisk Module Flasher:** Dukungan penuh untuk *flash* modul `.zip` Magisk langsung dari Windows Anda!
- 🧰 **Terminal Dapoy:** Terminal ADB bawaan khusus yang terintegrasi, memudahkan eksekusi baris perintah ke Android secara instan.
- 🛡️ **Magisk Root Patcher (BlueStacks & MSI):** Integrasi *patcher* otomatis untuk menyuntikkan Magisk Root murni (Kitsune/Delta) tanpa meninggalkan jejak atau merusak file VHD.

---

## 🛠️ Cara Penggunaan

1. Pastikan Anda menjalankan aplikasi dengan hak akses **Administrator** (Klik Kanan -> Run as Administrator).
2. Pilih emulator target dari menu *dropdown* di bagian atas.
3. Klik tombol **Refresh Status** untuk memastikan emulator telah terbaca.
4. Nikmati berbagai fitur _tweaking_ yang tersedia di masing-masing tab!

---

## 🔑 Cara Rooting (Langkah demi Langkah)

Berikut adalah urutan yang disarankan untuk melakukan *root* secara maksimal:

1. **Jalankan Emulator** yang ingin Anda root terlebih dahulu.
2. Buka tab **Root Manager** dan tentukan target **Emulator** beserta **Versi Android**-nya.
3. Cek koneksi ADB; pastikan opsi **ADB / Android Debug Bridge** sudah posisi **ON** pada setelan Emulator.
4. Klik tombol **Run Magisk Root Patcher** dan tunggu (berjalan otomatis) hingga muncul pemberitahuan selesai.
5. *Install* modul **NeoZygisk-v2.4-289-release.zip** melalui fitur Magisk Module Flasher.
6. *Install* modul **Vector_LPosed.zip** melalui fitur Magisk Module Flasher.
7. *Install* aplikasi **CorePatch.apk** melalui tab App Manager.
8. **Selesai!** Emulator Anda sudah ter-root dan siap digunakan secara optimal.
